# Looping with Numbers

![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow)

## Problem

Use a _for_ loop to display the natural numbers from $1$ to $50$.

**Input Format**

*There is no input*  

**Constraints**

 

**Output Format**

	1
    2
    3
    4
    5
    .
    .
    .
    .
    .
    50

## Solution

**Language:** Bash  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-26T08:22:15.089Z  

```sh
for((i=1;i<=50;i++))
do
echo $i
done

```
